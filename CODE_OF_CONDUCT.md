# Code of conduct

## Our commitment

This project is a place for people to do careful work on a hard problem: making research code
reproducible. Participants are expected to be respectful, specific and honest about what they
have and have not verified.

## Expected behaviour

- **Be precise.** "It doesn't work" is hard to act on; a command, an output and a version are
  actionable.
- **Separate fact from opinion**, especially in issues about a diagnosis or a benchmark result.
- **Assume good faith** and ask a clarifying question before assuming a motive.
- **Respect the honesty sections.** Do not ask maintainers to remove a documented limitation
  because it looks bad in a summary; help verify it instead.
- **Respect boundaries on time.** This is a volunteer project; unanswered for a few days is not
  a judgement.

## Unacceptable behaviour

- Harassment, insults, or discriminatory comments about any person or group.
- Publishing someone's private information without permission.
- Sharing other people's repository contents, credentials or datasets in issues.
- Deliberately submitting code or claims that are false, unverifiable, or copied without
  attribution.
- Sustained disruption of discussion.

## Scope

This applies to issues, pull requests, discussions, commit messages and any other project space.

## Reporting

Report concerns privately to the maintainer via a GitHub direct message or by opening a
security advisory at <https://github.com/liaooss/RunFixMCP/security/advisories/new>. Reports are
handled confidentially. Maintainers may remove content, close threads or block accounts that
violate this policy.
